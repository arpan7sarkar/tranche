# H5 Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build every Person H screen in `apps/web`: the design system Person E reuses, agency sign-in, onboarding, the Bryntum Gantt deal workspace with live updates and approvals, and the client portal with PayPal v6 checkout.

**Architecture:** Server Components read Postgres directly through small functions in `src/server/*`, and the same functions back JSON route handlers the client components refetch from. Live updates come from a Postgres `AFTER INSERT` trigger on `event` that calls `pg_notify`, one LISTEN connection per server process fanned out to Server-Sent Events streams, and native `EventSource` reconnection with `Last-Event-ID` replay. Money and state changes are never made here directly: the UI writes approvals, client `release` proposals and policy edits, and calls the H2 and H4 routes.

**Tech Stack:** Next.js 16.4 (App Router, Cache Components, Turbopack, `proxy.ts`), React 19.3, Tailwind 4.3, shadcn CLI 4.21, Better Auth 1.7.7, Bryntum Gantt 7.3.7 (trial) + `@bryntum/gantt-react` 7.3.7, `@paypal/paypal-js` 11.2.1 (`sdk-v6` subpath), postgres.js 3.4.9, Drizzle 0.45, Vitest 5, Playwright 1.64.

**Spec:** `docs/superpowers/specs/2026-10-08-tranche-design.md` (sections 5, 11, 12) and `docs/superpowers/plans/2026-10-08-00-foundation.md` (contracts and schema).

**Owner:** Person H. The design system (Tasks 1 and 2) must be merged by day 4 because Person E builds `deals/new`, `deals/[dealId]/negotiation` and `dashboard` on top of it.

## Global Constraints

- This Next.js version differs from older training data: before writing any Next.js code, read the matching guide in `apps/web/node_modules/next/dist/docs/` (at minimum `01-app/01-getting-started/15-route-handlers.md`, `16-proxy.md`, `08-caching.md` and `01-app/02-guides/authentication-with-cache-components.md`).
- `cacheComponents: true` is on: anything that reads `cookies()`, `headers()`, `params` or the database at request time must render inside a `<Suspense>` boundary.
- Route protection lives in `src/proxy.ts` (Next 16 renamed Middleware to Proxy); the proxy is only an optimistic cookie check, every page and route handler still authorizes on the server.
- Person E owns `src/app/(agency)/deals/new/**`, `src/app/(agency)/deals/[dealId]/negotiation/**`, `src/app/(agency)/dashboard/**`, `src/app/api/github/**`, `src/app/api/plans/**`, `src/app/api/negotiations/**`; do not create files there.
- Money is displayed only through `formatMoney`; never divide minor units inline in a component.
- Colors come only from tokens in `globals.css`; no raw hex or palette classes like `bg-zinc-50` in components.
- Every screen ships designed empty, loading and error states in light and dark (system preference).
- Strings produced by agents or clients (task names, reasoning, evidence summaries) are rendered as text, never as HTML.
- PayPal sandbox only (`environment: "sandbox"`).
- No em dash characters; comments only when they carry real value; conventional commits without AI co-author lines.

## Review Focus

- **Expired, tampered or malformed portal link** (`/portal/<token>` with one character changed, or past `expires_at`): shows the "link expired or invalid" page and leaks nothing about the deal - pinned in Task 10 Step 1.
- **Client double-clicks Release, or two tabs release at once**: exactly one `proposed_action` row exists and the second request reports `already_submitted` - pinned in Task 11 Step 1.
- **Approval decided twice** (agency clicks Approve while the client rejects, or a retry): the first decision wins, the second returns `already_decided`, and only one `approval.decided` event is written - pinned in Task 9 Step 1.
- **SSE connection drops and reconnects with `Last-Event-ID`**: every event written while disconnected is replayed in order, none twice - pinned in Task 6 Step 1.
- **Agency member from another workspace opens a deal URL or its API**: gets a 404, not the deal - pinned in Task 5 Step 1.

```ts
import { type Money, minorUnitExponent } from "@tranche/contracts";

export function formatMoney(m: Money, locale = "en-US"): string {
  const exponent = minorUnitExponent(m.currency);
  return new Intl.NumberFormat(locale, {
    style: "currency",
    currency: m.currency,
    minimumFractionDigits: exponent,
    maximumFractionDigits: exponent,
  }).format(m.minor / 10 ** exponent);
}

export function totalOf(currency: string, minors: number[]): Money {
  return { currency, minor: minors.reduce((sum, n) => sum + n, 0) };
}
```

```ts
import type { MachineCheck } from "@tranche/contracts";

export function describeCheck(check: MachineCheck): string {
  switch (check.kind) {
    case "pr_merged":
      return `Pull request merged into ${check.base} in ${check.repo}`;
    case "ci_green":
      return `CI passes in ${check.repo}`;
    case "url_live":
      return `${check.url} is live`;
    case "lighthouse":
      return `Lighthouse ${check.category} ${check.min}+ on ${check.url}`;
  }
}
```

```ts
import "server-only";
import { schema } from "@tranche/db";
import { eq } from "drizzle-orm";
import { headers } from "next/headers";
import { redirect } from "next/navigation";
import { auth } from "./auth";
import { getDb } from "./db";

export type Member = { userId: string; name: string; workspaceId: string; workspaceName: string };

async function memberFor(h: Headers): Promise<Member | null> {
  const session = await auth.api.getSession({ headers: h });
  if (!session) return null;
  const [row] = await getDb()
    .select({ workspaceId: schema.workspace.id, workspaceName: schema.workspace.name })
    .from(schema.workspaceMember)
    .innerJoin(schema.workspace, eq(schema.workspace.id, schema.workspaceMember.workspaceId))
    .where(eq(schema.workspaceMember.userId, session.user.id))
    .limit(1);
  return row ? { userId: session.user.id, name: session.user.name, ...row } : null;
}

export async function getMember(): Promise<Member | null> {
  return memberFor(await headers());
}

export async function requireMember(): Promise<Member> {
  const member = await getMember();
  if (!member) redirect("/sign-in");
  return member;
}

export function memberOrNull(request: Request): Promise<Member | null> {
  return memberFor(request.headers);
}
```

```ts
    .select({ deal: schema.deal, clientName: schema.client.name, clientEmail: schema.client.email })
```

```ts
import type { StreamEvent } from "@/lib/sse";

type Listener = (e: StreamEvent) => void;

const listeners = new Set<Listener>();
let ready: Promise<unknown> | undefined;

function start() {
  const sql = postgres(process.env.DATABASE_URL as string, { max: 1 });
  return sql.listen("tranche_events", (payload) => {
    const event = JSON.parse(payload) as StreamEvent;
    for (const listener of listeners) listener(event);
  });
}

export async function subscribe(listener: Listener): Promise<() => void> {
  ready ??= start();
  await ready;
  listeners.add(listener);
  return () => listeners.delete(listener);
```

```ts
        if (e.id <= lastSent) return;
        lastSent = e.id;
        controller.enqueue(encoder.encode(sseFrame(e)));
      };
      const unsubscribe = await subscribe((e) => {
        if (e.dealId !== dealId) return;
        if (replaying) queued.push(e);
        else send(e);
      });
      const missed = await getDb()
        .select()
        .from(schema.event)
        .where(and(eq(schema.event.dealId, dealId), gt(schema.event.id, after)))
        .orderBy(asc(schema.event.id));
      for (const e of missed) send({ id: e.id, dealId: e.dealId, milestoneId: e.milestoneId, type: e.type });
      replaying = false;
      for (const e of queued) send(e);

      const heartbeat = setInterval(() => controller.enqueue(encoder.encode(": ping\n\n")), 25_000);
      request.signal.addEventListener("abort", () => {
        clearInterval(heartbeat);
        unsubscribe();
        controller.close();
      });
    },
  });

  return new Response(stream, {
    headers: {
      "Content-Type": "text/event-stream",
      "Cache-Control": "no-cache, no-transform",
      Connection: "keep-alive",
      "X-Accel-Buffering": "no",
    },
  });
}
```

Subscribing before the replay query, then draining the queue, closes the gap between "read missed events" and "start listening".
`resolveMagicLink` comes from `@tranche/db` (foundation Task 5).

```ts
import type { MilestoneState } from "@tranche/contracts";
import { milestoneTone } from "@/lib/milestone-tone";
import { formatMoney } from "@/lib/money";
import type { DealView } from "@/server/deals";

export type GanttTask = {
  id: string;
  name: string;
  startDate?: string;
  endDate?: string;
  manuallyScheduled?: boolean;
  readOnly?: boolean;
  draggable?: boolean;
  resizable?: boolean;
  expanded?: boolean;
  children?: GanttTask[];
  kind: "group" | "task" | "payment";
  price?: string;
  holdLabel?: string;
  stateLabel?: string;
};

export type GanttDependency = { id: string; fromTask: string; toTask: string };

export const LOCKED_STATES: ReadonlySet<MilestoneState> = new Set(["released", "paid_out", "refunded", "cancelled", "disputed"]);

export function addDays(iso: string, days: number): string {
  const d = new Date(`${iso}T00:00:00Z`);
  d.setUTCDate(d.getUTCDate() + days);
  return d.toISOString().slice(0, 10);
}

export function toIsoDate(d: Date): string {
  const pad = (n: number) => String(n).padStart(2, "0");
  return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())}`;
}

export function toGanttData(view: DealView): { tasks: GanttTask[]; dependencies: GanttDependency[] } {
  const dependencies: GanttDependency[] = view.dependencies.map((d) => ({
    id: `${d.fromTaskId}->${d.toTaskId}`,
    fromTask: d.fromTaskId,
    toTask: d.toTaskId,
  }));

  const tasks = view.milestones.map((m): GanttTask => {
    const locked = LOCKED_STATES.has(m.state);
    const children: GanttTask[] = view.tasks
      .filter((t) => t.milestoneId === m.id)
      .map((t) => ({
        id: t.id,
        name: t.title,
        startDate: t.startDate,
        endDate: addDays(t.startDate, t.durationDays),
        manuallyScheduled: true,
        readOnly: locked,
        draggable: !locked,
        resizable: false,
        kind: "task",
      }));
    const end = m.endDate ?? children.map((c) => c.endDate as string).sort().at(-1);
    const paymentId = `pay:${m.id}`;
    for (const c of children) dependencies.push({ id: `${c.id}->${paymentId}`, fromTask: c.id, toTask: paymentId });
    children.push({
      id: paymentId,
      name: `${m.title} payment`,
      ...(end ? { startDate: end, endDate: end } : {}),
      manuallyScheduled: true,
      readOnly: true,
      draggable: false,
      resizable: false,
      kind: "payment",
      price: formatMoney({ currency: view.deal.currency, minor: m.priceMinor }),
      holdLabel: milestoneTone(m.state).label,
      stateLabel: m.state,
    });
    return { id: `ms:${m.id}`, name: m.title, expanded: true, readOnly: locked, draggable: false, resizable: false, kind: "group", children };
  });

  return { tasks, dependencies };
}
```

```ts
import { schema } from "@tranche/db";
import { and, eq } from "drizzle-orm";
import { getDb } from "@/server/db";
import { createMagicLink } from "@tranche/db";
import { memberOrNull } from "@/server/session";

export async function POST(request: Request, ctx: RouteContext<"/api/deals/[dealId]/send">) {
  const member = await memberOrNull(request);
  if (!member) return Response.json({ error: "unauthorized" }, { status: 401 });
  const { dealId } = await ctx.params;
  const db = getDb();
  const [row] = await db
    .select({ deal: schema.deal, client: schema.client })
    .from(schema.deal)
    .innerJoin(schema.client, eq(schema.client.id, schema.deal.clientId))
    .where(and(eq(schema.deal.id, dealId), eq(schema.deal.workspaceId, member.workspaceId)));
  if (!row) return Response.json({ error: "not_found" }, { status: 404 });
  if (row.deal.status !== "draft") return Response.json({ error: "already_sent" }, { status: 409 });

  const portalUrl = await db.transaction(async (tx) => {
    const { url } = await createMagicLink(tx, { clientId: row.client.id, dealId });
    await tx.update(schema.deal).set({ status: "sent", updatedAt: new Date() }).where(eq(schema.deal.id, dealId));
    await tx.insert(schema.event).values({
      dealId,
      type: "deal.plan_sent",
      payload: { portalUrl: url, clientEmail: row.client.email },
    });
    return url;
  });
  return Response.json({ portalUrl });
}
```

```ts
import { type Db, schema } from "@tranche/db";
import { and, eq, isNull } from "drizzle-orm";

type Input = {
  approvalId: string;
  side: "agency" | "client";
  scope: { workspaceId: string } | { dealId: string };
  decidedBy: string;
  decision: "approved" | "rejected";
};

export async function decideApproval(db: Db, input: Input): Promise<"decided" | "already_decided" | "not_found"> {
  return db.transaction(async (tx) => {
    const [row] = await tx
      .select({ approval: schema.approval, action: schema.proposedAction, workspaceId: schema.deal.workspaceId })
      .from(schema.approval)
      .innerJoin(schema.proposedAction, eq(schema.proposedAction.id, schema.approval.proposedActionId))
      .innerJoin(schema.deal, eq(schema.deal.id, schema.proposedAction.dealId))
      .where(and(eq(schema.approval.id, input.approvalId), eq(schema.approval.side, input.side)))
      .for("update");
    if (!row) return "not_found";
    const inScope =
      "workspaceId" in input.scope ? row.workspaceId === input.scope.workspaceId : row.action.dealId === input.scope.dealId;
    if (!inScope) return "not_found";

    const updated = await tx
      .update(schema.approval)
      .set({ decision: input.decision, decidedBy: input.decidedBy, decidedAt: new Date() })
      .where(and(eq(schema.approval.id, input.approvalId), isNull(schema.approval.decision)))
      .returning({ id: schema.approval.id });
    if (updated.length === 0) return "already_decided";

    await tx
      .update(schema.proposedAction)
      .set({ status: input.decision, decidedAt: new Date(), decisionReason: `${input.side} ${input.decision}` })
      .where(eq(schema.proposedAction.id, row.action.id));
    await tx.insert(schema.event).values({
      dealId: row.action.dealId,
      type: "approval.decided",
      payload: { approvalId: input.approvalId, proposedActionId: row.action.id, side: input.side, decision: input.decision },
    });
    return "decided";
  });
}
```

```ts
const Body = z.object({ decision: z.enum(["approved", "rejected"]) });

export async function POST(request: Request, ctx: RouteContext<"/api/approvals/[id]/decide">) {
  const member = await memberOrNull(request);
  if (!member) return Response.json({ error: "unauthorized" }, { status: 401 });
  const parsed = Body.safeParse(await request.json().catch(() => null));
  if (!parsed.success) return Response.json({ error: "invalid_body" }, { status: 400 });

  const result = await decideApproval(getDb(), {
    approvalId: id,
    side: "agency",
    scope: { workspaceId: member.workspaceId },
    decidedBy: member.userId,
    decision: parsed.data.decision,
  });
  const status = result === "decided" ? 200 : result === "already_decided" ? 409 : 404;

}
```

```ts
import { type Policy, ProposedActionInput } from "@tranche/contracts";
import { type Db, schema } from "@tranche/db";
import { and, eq, sql } from "drizzle-orm";

export function defaultClientPolicy(totalMinor: number): Policy {
  return {
    perActionMaxMinor: totalMinor,
    perMilestoneMaxMinor: totalMinor,
    perDealMaxMinor: totalMinor,
    autoReleaseAfterHours: null,
    cooldownMinutes: 0,
    alwaysAsk: [],
  };
}

export async function submitClientRelease(db: Db, input: { dealId: string; milestoneId: string }) {
  const [m] = await db
    .select({ milestone: schema.milestone, currency: schema.deal.currency })
    .from(schema.milestone)
    .innerJoin(schema.deal, eq(schema.deal.id, schema.milestone.dealId))
    .where(and(eq(schema.milestone.id, input.milestoneId), eq(schema.milestone.dealId, input.dealId)));
  if (!m || m.milestone.state !== "release_pending") return "not_releasable" as const;

  const proposal = ProposedActionInput.parse({
    dealId: input.dealId,
    agent: "human",
    side: "client",
    reasoning: "The client released this milestone in the portal.",
    evidenceIds: [],
    idempotencyKey: `release:${input.milestoneId}:client`,
    payload: { type: "release", milestoneId: input.milestoneId, amount: { currency: m.currency, minor: m.milestone.priceMinor } },
  });
  const inserted = await db
    .insert(schema.proposedAction)
    .values({ ...proposal, type: proposal.payload.type })
    .onConflictDoNothing({ target: schema.proposedAction.idempotencyKey })
    .returning({ id: schema.proposedAction.id });
  return inserted.length > 0 ? ("submitted" as const) : ("already_submitted" as const);
}

export async function setAutoRelease(db: Db, input: { dealId: string; hours: 24 | 72 | 168 | null }): Promise<Policy> {
  const [row] = await db
    .select({
      policy: schema.deal.clientPolicy,
      total: sql<number>`coalesce((select sum(${schema.milestone.priceMinor}) from ${schema.milestone} where ${schema.milestone.dealId} = ${schema.deal.id}), 0)::bigint`.mapWith(Number),
    })
    .from(schema.deal)
    .where(eq(schema.deal.id, input.dealId));
  if (!row) throw new Error(`Deal ${input.dealId} not found`);
  const policy: Policy = { ...(row.policy ?? defaultClientPolicy(row.total)), autoReleaseAfterHours: input.hours };
  await db.update(schema.deal).set({ clientPolicy: policy, updatedAt: new Date() }).where(eq(schema.deal.id, input.dealId));
  return policy;
}
```

```tsx
        onChange={(e) => save(e.target.value)}
```

```tsx
"use client";

import { loadCoreSdkScript } from "@paypal/paypal-js/sdk-v6";
import { useRouter } from "next/navigation";
import { useEffect, useRef, useState } from "react";
import { toast } from "sonner";
import { Button } from "@/components/ui/button";

type Status = "loading" | "ready" | "busy" | "unavailable";
type Session = { start: (options: { presentationMode: "auto" | "popup" }, order: Promise<{ orderId: string }>) => Promise<void> };

export function FundButton({ token, milestoneId, currency, label }: { token: string; milestoneId: string; currency: string; label: string }) {
  const router = useRouter();
  const [status, setStatus] = useState<Status>("loading");
  const session = useRef<Session | null>(null);

  useEffect(() => {
    let cancelled = false;
    (async () => {
      const paypal = await loadCoreSdkScript({ environment: "sandbox" });
      const clientId = process.env.NEXT_PUBLIC_PAYPAL_CLIENT_ID;
      if (!paypal || !clientId || cancelled) return setStatus("unavailable");
      const sdk = await paypal.createInstance({ clientId, components: ["paypal-payments"], pageType: "checkout" });
      const eligible = await sdk.findEligibleMethods({ currencyCode: currency });
      if (cancelled) return;
      if (!eligible.isEligible("paypal")) return setStatus("unavailable");
      session.current = sdk.createPayPalOneTimePaymentSession({
        onApprove: async ({ orderId }: { orderId: string }) => {
          const res = await fetch(`/api/portal/${token}/orders/${orderId}/approved`, { method: "POST" });
          if (res.ok) toast.success("Payment approved. Funds are held by PayPal until you release them.");
          else toast.error("PayPal approved the payment but we could not confirm it. Refresh in a moment.");
          setStatus("ready");
          router.refresh();
        },
        onCancel: () => setStatus("ready"),
        onError: () => {
          toast.error("PayPal could not complete the payment.");
          setStatus("ready");
        },
      }) as Session;
      setStatus("ready");
    })().catch(() => !cancelled && setStatus("unavailable"));
    return () => {
      cancelled = true;
    };
  }, [currency, token, router]);

  function fund() {
    if (!session.current) return;
    setStatus("busy");
    const order = fetch(`/api/portal/${token}/milestones/${milestoneId}/fund`, { method: "POST" }).then(async (res) => {
      if (!res.ok) throw new Error(`fund failed: ${res.status}`);
      const { orderId } = (await res.json()) as { orderId: string };
      return { orderId };
    });
    session.current.start({ presentationMode: "auto" }, order).catch(() => {
      toast.error("Could not open PayPal.");
      setStatus("ready");
    });
  }

  if (status === "unavailable") {
    return <p className="text-sm text-destructive">PayPal is unavailable right now. Try again later.</p>;
  }
  return (
    <Button onClick={fund} disabled={status !== "ready"} className="self-start">
      {status === "loading" ? "Loading PayPal" : status === "busy" ? "Waiting for PayPal" : label}
    </Button>
  );
}
```

`session.start` is called synchronously inside the click handler with a pending order promise, so browsers do not block the PayPal popup.
